# YuNet face detector

`face_detection_yunet_2023mar.onnx` is the OpenCV Zoo YuNet face-detection
model.

- Source: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
- Direct download:
  `https://github.com/opencv/opencv_zoo/raw/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx`
- License: Apache-2.0 (opencv/opencv_zoo)
- Size: ~230 KB
- MD5: `4ae92eeb150c82ce15ac80738b3b8167`

If this file is missing, `smartcrop.py` falls back to OpenCV's bundled Haar
cascade (zero download, lower accuracy).
